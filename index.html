Command & Control System for Fire Emergency

AngularSpring BootWebSocketsGIS MapsHibernateSQL

A control-room system that operators use to track fire incidents and send fire vehicles to the scene.

  • Request BackupOperators can ask for extra vehicles or teams for an ongoing incident. Each request is linked to the original incident, can be cancelled, and is fully logged.
  • Live updatesNew incidents, status changes and vehicle locations arrive over WebSockets, and the connection reconnects itself after network drops.
  • Map viewsIncidents, vehicle tracking, and the nearest fire station with its arrival time.
  • SecurityHMAC-SHA256 checksums reject tampered API data. Session details are encrypted, and idle users are logged out.
  • Readiness screensScreens that show which units and stations are ready to respond, covered by Jasmine tests.
